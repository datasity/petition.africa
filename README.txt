PETITION.AFRICA  -  prototype
Open index.html in any browser. Works offline: all maps are bundled.

Pages: index (home), browse, petition, start (5-step wizard), map, account, about, admin.
Admin demo password: petitionafrica   |   Phone sign-in uses an on-screen demo code (no SMS).

Maps: all 54 African countries from geoBoundaries (open licences, attribution required).
  50 countries with two levels (state/region + local area), 4 with one level (Algeria, Libya, Mauritius, Seychelles).
Leaders (assets/leaders.js, checked 26 Oct 2026): heads of state for all 54;
  governors (Nigeria 36 + FCT, Kenya 47), regional ministers (Ghana 16), premiers (South Africa 9).
  Other offices show their title; add names in Admin > Leaders or accept user suggestions in Admin > Reports.
Petition writer: assets/writer.js (template-based, no AI service).
Share cards: assets/cards.js (1080x1080, 1080x1920, 1200x630 PNG).
Data lives in browser storage. Demo petitions and counts are illustrative.
To go live: server database, SMS OTP provider, moderation team, data protection registration per country.
